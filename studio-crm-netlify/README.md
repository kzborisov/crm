# Studio CRM — Netlify Edition v2

Безплатен, самостоятелен CRM за един потребител, предназначен за снимки, видео проекти и финансов отчет. Интерфейс на български, мобилен дизайн, всички суми в евро.

## Какво има вътре

- Обзор: реално получени приходи, платени разходи, финансов резултат, 6-месечна графика, очаквани плащания, follow-up контакти.
- Клиенти: контакт, бизнес, Instagram, имейл, телефон, бележки.
- Проекти: етап, договорена стойност, дата на снимки, дата за follow-up, бележки, получено и остатък.
- Финанси: приходи/разходи, категории, връзка към клиент и проект.
- Експорт: CSV и **пълен JSON архив**; възстановяване от JSON архив.
- Защита: лична парола, сесия в HttpOnly/Secure/SameSite=Strict cookie, CSRF проверки, вход само с конфигурирани секретни променливи.
- Съхранение: **Netlify Blobs** със strong consistency и условни записи (ETag) при обновяване.

## Публикуване — Netlify Free ($0)

1. Разархивирай `studio-crm-netlify-v2.zip`. Файловете `netlify.toml`, `package.json`, папките `public/` и `netlify/` трябва да са **в основната директория** на репото.
2. В GitHub създай **private repository** `studio-crm` и качи файловете. Не качвай `.env`, пароли или финансови архиви.
3. Отвори https://app.netlify.com/ → **Add new project → Import an existing project → GitHub** → избери твоето репо.
4. Build settings: **Build command: празно** (няма frontend build), **Publish directory: `public`**. `netlify.toml` посочва папката за функции `netlify/functions`.
5. В Netlify → **Project configuration → Environment variables** добави тези променливи:
   - `CRM_PASSWORD` = уникална парола от поне 16–20 случайни символа (минимум технически 12).
   - `SESSION_SECRET` = случаен дълъг ключ, поне 32 символа. Генерирай го локално с `openssl rand -hex 32` или `python -c "import secrets; print(secrets.token_urlsafe(48))"`.
6. Натисни **Deploy** (или **Trigger deploy** след въвеждане на env variables). Netlify ще даде HTTPS адрес `име-на-сайта.netlify.app`.
7. Отвори URL адреса, влез с `CRM_PASSWORD`, добави клиента и проекта. На телефона избери **Add to Home Screen**.

**ВАЖНО:** Няма нужда от Supabase, Railway, отделен PostgreSQL или домейн. Данните са в Netlify Blobs и остават налични при нови деплои. Не избирай “drag-and-drop static deploy” за тази версия — използвай GitHub интеграцията, за да се инсталират зависимостите и изградят Functions.

## Цена, ограничения и архиви

- Netlify **Free**: $0/месец, 300 credits/месец (актуално ноември 2026). При изчерпването им проектът може да бъде паузиран до новия период. Не се активира автоматично платен план. Проверявай Usage & billing.
- Netlify Blobs е **Beta** (ноември 2026), поддържа постоянни site-wide данни. Прави **JSON архив веднъж седмично** от меню **Още** и го пази сигурно отделно от Netlify.
- Данните са в Netlify Blobs, не в браузърския localStorage, т.е. виждаш едно и също от компютър и телефон.
- Едновременно редактиране в няколко раздела: записът ще бъде отказан при установена промяна от друг прозорец вместо да презапише тихомълком данните.
- Не е счетоводен продукт, няма фактуриране, ДДС, данъци, bank sync.

## Възможни грешки

- **„Системата не е конфигурирана“**: добави `CRM_PASSWORD` и `SESSION_SECRET` и направи redeploy.
- **„Грешна парола“**: използвай стойността на `CRM_PASSWORD`, не Netlify паролата.
- **„Проблем със съхранението“**: провери Netlify Function logs и Data & Storage → Blobs; провери usage лимитите.
- **Деплойва само статично**: увери се, че Netlify е свързан с GitHub репото и `netlify.toml` е в root директорията; Functions трябва да са построени.
- **Променил си `SESSION_SECRET`**: старите сесии се прекратяват и трябва да влезеш отново. Данните остават.

## Прехвърляне от старата Python версия

Това е **нова, Netlify-съвместима реализация**. Ако вече си въвеждал данни в SQLite версията v1, **не разчитай, че ще се импортират автоматично** — нужна е миграция към JSON структурата. Ако не си въвеждал данни, просто използвай новата версия.

## Технически бележки

Stack: vanilla HTML/CSS/JS, Netlify Functions (Node 20+) и Netlify Blobs (`@netlify/blobs`). Няма изнесена база данни. За твърде голям или многопотребителски CRM по-подходяща е истинска SQL база.

Локални тестове на валидацията и авторизацията (не извикват Netlify): `npm test`. Локално стартиране на цялото приложение изисква `npm install`, `npx netlify dev` и env променливи (Netlify CLI). Пакетът не включва `node_modules`.

Сигурност: секретните стойности трябва да са само в Netlify Environment variables, не в JS, ZIP или Git. Входовете са защитени от cookie, а всички финансови API маршрути проверяват автентикацията. Използвай достатъчно сложна парола. Понеже Netlify Functions са serverless и няма вграден persistent brute-force limiter, за публичен сайт силната уникална парола е задължителна.
